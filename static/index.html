أداة محلية لتنزيل ملفات PDF من تيليجرام

TelePDF

نزّل كل ملفات PDF من قناة أو حساب تيليجرام عام إلى جهازك، مع فهرس CSV محلي، وبدون رفع الملفات إلى أي خدمة خارجية.

محلي فقط جلسة تيليجرام شخصية فهرس CSV تلقائي
1. جهّز مفاتيح Telegram API 2. سجّل الدخول برقمك 3. الصق المصدر وابدأ التنزيل

دليل سريع

قبل أول تشغيل

مفاتيح Telegram API

ادخل إلى my.telegram.org وأنشئ تطبيقاً، ثم انسخ api_id وapi_hash.

صيغة رقم الهاتف

اكتب رقمك كاملاً بصيغة دولية مثل +965XXXXXXXX.

صيغة المصدر

استخدم فقط @channelname أو https://t.me/channelname.

مكان الحفظ

ملفات PDF تحفظ في المجلد الذي تختاره، والجلسة والإعدادات تحفظ محلياً تحت ~/.telepdf.

حماية المفاتيح

يتم حفظ API Hash والجلسة الجديدة في التخزين الآمن للنظام بدل حفظها كنص مكشوف داخل ملف عادي.

الخطوة 1

ربط حساب تيليجرام

احفظ المفاتيح ورقم الهاتف، ثم اطلب كود تيليجرام وأكمل تسجيل الدخول.

الترتيب الصحيح: احفظ الإعدادات أولاً، ثم اضغط إرسال الكود، ثم اكتب الكود الذي يصلك. إذا كان حسابك فيه 2FA اكتب كلمة المرور أيضاً.
ماذا يعني حذف البيانات المحلية؟ يحذف الإعدادات والجلسة والسجل المحلي فقط، ولا يحذف ملفات PDF التي سبق تنزيلها إلى جهازك.

الخطوة 2

بدء تنزيل الأرشيف

ضع المصدر العام وحدد مجلد الحفظ على جهازك، ثم ابدأ المهمة.

مهم: إذا شغّلت نفس المصدر مرة ثانية مع نفس مجلد الحفظ، فالتطبيق يتجاوز الرسائل التي سبق تنزيلها بدل أن يبدأ من الصفر.
